# Pénielle Art Graphic — site multipage

React + TypeScript (Vite, React Router, Lenis). Design et animations issus du projet `certificate` ; palette et contenu issus du projet `pag`.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

Pages : `/`, `/formations`, `/formations/:id`, `/services`, `/ceremonies`, `/a-propos`, `/actualites`, `/contact`.
Les contenus sont dans `src/data/pagData.ts`.

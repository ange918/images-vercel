# Pénielle Art Graphic — site multipage

React + TypeScript (Vite, Tailwind CSS v4, React Router). Design et animations issus du projet `cap` ; contenu issu du projet `pag`.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

Pages : `/`, `/formations`, `/formations/:id`, `/services`, `/ceremonies`, `/a-propos`, `/actualites`, `/contact`.
Les contenus sont dans `src/data/pagData.ts`.
